How to edit?

(https://github.com/Beevern/RhythmAimGame)
Install a unity editor from https://unity.com/download
Install GitHub desktop to pull all changes added to the project
Download the latest release from the release tab on the right of the github page
Extract the files into a locatable folder
In top right of Unity Hub, add project -> go to the folder where the project is stored -> open
Open the project with Unity Hub
Double click on scripts to open them.

How to play?

OUTDATED BUILD!
Head to (https://drive.google.com/file/d/1fqXNYUfz0ivqmXtsh09KTFLmxgQ6gM5l/view?usp=sharing)
Download the zip folder
Extract the files into a locatable folder
Run the .exe file named "RhythmGame3d"
Done!
The objective is to click the blue note which spawns to the beats/lyrics of the song. Clicking too early or too late will result in a penalty!
